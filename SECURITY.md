# Security policy

Report suspected vulnerabilities using [GitHub private vulnerability reporting](https://github.com/Lseven-zzw/modeldesk-harness/security/advisories/new). Include the affected commit, deployment details, impact, and a minimal reproduction. Remove real credentials and employee data before attaching artifacts. Use public issues for ordinary bugs.

请通过 [GitHub 私密漏洞报告](https://github.com/Lseven-zzw/modeldesk-harness/security/advisories/new)报告安全问题，附受影响的提交、部署环境、影响范围和最小复现步骤。提交附件前请移除真实凭据和员工数据。普通缺陷可在 Issues 中报告。
